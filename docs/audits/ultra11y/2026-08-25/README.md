# Pièces visuelles du rapport ultra11y RGAA

Captures extraites du rapport ultra11y produit le 25 août 2026 pour Egapro.

Ces images montrent l’état initial des pages dans un viewport de 1280 × 720. Elles permettent d’identifier la route et le composant visé, mais ne constituent pas une preuve d’un défaut dynamique au zoom 200 % ou après surcharge d’espacement : le rapport ne fournit pas de capture de ces états transformés. Les tickets concernés demandent donc d’abord une reproduction manuelle.

Cette branche est une archive de preuves liée à l’issue parente `#4311`. Elle ne contient aucun correctif applicatif.
